## Fonts
The home page uses the reimagine stack `"Segoe UI Variable Text"` / `"Segoe UI Variable Display"`, served from `www.microsoft.com/etc.clientlibs/.../segoe-sans/west-european/latest.woff2` **without** `Access-Control-Allow-Origin` (checked from a localhost origin) and licensed — not loadable cross-origin, not rehosted. The prototype declares the live stack verbatim (`"Segoe UI Variable Text", "Segoe UI", segoeui, …`), which falls through to canon's `SegoeUI` @font-face (c.s-microsoft.com, CORS `*`). Weight 500 renders as the nearest static face. Gate: every declared face loaded on both sides; visual-diff FONT MISMATCH on the Variable headings is this fallback (justified).
