# accordion-faq

Custom **accordion** block. Purpose: faq.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. One row per Q&A: cell 1 = question, cell 2 = answer.

Optional title: a first single-cell row containing a heading is used as the block title. If there is
none, a heading authored as default content directly above the block (last element of the preceding
default-content wrapper) is moved into the block header so it sits beside the Expand all / Collapse all controls.

## Supported variations

No variations.
