# tabs-media

Custom **tabs** block. Purpose: media-switcher.

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one row per tab.

| Cell 1 | Cell 2 |
| --- | --- |
| Tab label | Media (picture and/or link to an .mp4), then optional caption text and a spec list |

- **Colour options:** add one picture per colour, each followed by a line `Shown in <colour>`, optionally with the swatch colour code, e.g. `Shown in Black #000000`. With two or more, the tab shows a pill of colour swatches that switches the picture and the caption; the code sets the swatch colour (without it, a standard colour for the name is used) and is never shown to visitors.
- **Spec list:** list items written as **label**, value, detail on separate lines become stat tiles.
