# bing-panel

Custom **columns** block. Purpose: side-by-side media panel / slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: row: media (picture or .mp4 link) | text (tag, heading, description, CTAs) | optional row options (rounded, rounded-block, yellow); 2+ rows = slider.

## Supported variations

| Variation | Option class |
| --- | --- |
| Reversed | `reversed` |
| 60/40 | `sixtyforty` |
| Gray | `gray` |
| Light blue | `lightblue` |
| Features | `features` |
| Compact | `compact` |
