# support-cards

Custom **cards** block. Purpose: support home card groups.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: head row (heading, no image); one row per card: image | text (linked heading = card link); foot row (link, no image/heading).

## Supported variations

| Products | `products` |
| Features | `features` |
| Groups | `groups` |
