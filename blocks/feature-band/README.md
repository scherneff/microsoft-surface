# feature-band

Custom **columns** block. Purpose: media + copy features.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional head row (heading + intro); one row per feature: image(s) + eyebrow, heading, body, CTA (video CTA opens modal).
