# accordion-media

Custom **accordion** block. Purpose: use-case-showcase.

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one row per item. A full-screen video (or poster) plays behind the open item.

| Row | Cell 1 | Cell 2 |
| --- | --- | --- |
| Intro (optional, first row) | Wallpaper image (landscape), optional second image (portrait crop) | Section heading |
| Item (one per row) | Label | Poster image, copy, link to the item's video (.mp4) |

- With an intro row, the block pins for two screens of scrolling: the wallpaper and heading show first and fade out a quarter of the way through to reveal the items and videos (and come back when scrolling up). Without one, the block is a single screen.
- Labels written in sentence case use the sans label style; all-caps labels keep the mono display style.
