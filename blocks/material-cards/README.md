# material-cards

Custom **cards** block. Purpose: image cards under an area heading.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional head (default content before block or first row without image); one row per card: image + heading + copy + optional CTA.

## Supported variations

| Variation | Option class |
| --- | --- |
| Peach | `peach` |
| Dark | `dark` |
| Flat | `flat` |
