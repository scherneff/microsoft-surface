# article-listing

Custom **cards** block. Purpose: filterable article card listing.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: head row: title + optional search label; one row per article: image | read time, linked heading, description; tabs + pagination generated.
