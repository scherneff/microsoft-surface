# text-cards

Custom **cards** block. Purpose: text cards under an area heading.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional head (h2 + copy); one row per card: h3 + copy and/or CTA (optional leading image/icon).

## Supported variations

| Variation | Option class |
| --- | --- |
| Peach | `peach` |
| Divider | `divider` |
| With icons | `with-icons` |
| Tiles | `tiles` |
| Halves | `halves` |
| Band | `band` |
